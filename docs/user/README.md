# User Documentation

**In short:** step-by-step guides for everyone who uses the application, organized by role.

New pages start from the [user guide template](https://github.com/workforce-ops-app/.github/blob/main/docs/templates/user-guide.md).

| Role | Guides |
|---|---|
| Employee | to do: view schedule, request time off, request coverage, complete tasks |
| Manager | to do: manage schedules, approve requests, assign tasks, post announcements |
| Company administrator | to do: roles and permissions, departments and teams, workflow settings |
| Company owner | to do: administrators, security policies, audit records |
